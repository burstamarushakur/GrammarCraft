## y4-supported

Original scaffolded practice for class 4K, using selected Year 4 SK grammar: quantities, ownership, verb + ing or infinitive, regular and irregular past forms, could, going to, why/because and short-adjective comparisons. The Year 4 syllabus explicitly recycles present simple and present continuous, used together here to contrast routines and actions now. Small choices, short word banks, direct hints, audio and retries support pupils step by step. This is a selected practice pack, not coverage of every Year 4 grammar item or a complete assessment of a DSKP learning standard or PBD performance level.

## 6S — 20 aktiviti KBAT (50%)

Sumber definisi HOTS: DSKP Tahun 6, halaman cetak 12. Aktiviti terpilih memerlukan hubungan antara petunjuk atau penilaian pilihan dalam situasi. Label kognitif dan rasional diberikan untuk semakan guru.

| Aktiviti | Aras | Rasional |
|---|---|
| y6h-market:1 | analyse | The pupil separates two material-to-product relationships, detects the swapped references and selects an edit that restores both; every option uses the same correct passive form. |
| y6h-market:2 | evaluate | The pupil evaluates three choices against a minimum quantity and a no-waste condition, then selects the reasoned recommendation; the grammar is correct in every option. |
| y6h-market:3 | analyse | The pupil relates two quantities to a shared need and tests both parts of a contrasting statement; recalling the phrase enough cups does not identify the correct note. |
| y6h-market:4 | evaluate | The pupil evaluates a practical choice using material properties and current weather, rejecting notes with an unsupported reason despite their grammatical form. |
| y6h-bridge:2 | analyse | The pupil tracks the original speaker, current speaker and owner through a change of viewpoint; every option uses had, so tense recall alone is insufficient. |
| y6h-bridge:3 | analyse | The pupil compares a draft against two different sets of actors, locates the inaccurate reference and chooses an edit that preserves both events. |
| y6h-bridge:4 | analyse | The pupil applies a time restriction to the present situation, derives the permission statement and checks tag polarity; all three offered questions have grammatical tags. |
| y6h-mine:1 | evaluate | The pupil compares competing explanations with incomplete evidence and selects an appropriately uncertain claim; every option is a grammatical sentence. |
| y6h-mine:2 | analyse | The pupil distinguishes checked locations from an unchecked location, then tests a two-part statement for the correct degree of certainty in each part. |
| y6h-mine:3 | analyse | The pupil connects weather, an opening and a wet floor to infer a plausible cause, while retaining uncertainty; all options contain the same correct modal form. |
| y6h-mine:4 | analyse | The pupil checks two separate claims against a four-person set, detects both overgeneralisation and a false existence claim, and selects the only edit that fixes both. |
| y6h-portal:1 | analyse | The pupil combines a weather rule with a separate hall-opening restriction, eliminates both immediate places and chooses a feasible future outcome; every option has a grammatical first conditional. |
| y6h-portal:2 | evaluate | The pupil calculates an arrival time and tests it against an opening constraint to choose a feasible plan; all options use the same correct going to structure. |
| y6h-portal:3 | analyse | The pupil combines travel stages for two alternatives and checks the predicted outcome of each conditional rather than selecting a verb form by recall. |
| y6h-portal:4 | evaluate | The pupil evaluates the certainty of two different pieces of information and selects a message that treats the planned action and uncertain forecast appropriately. |
| y6h-rescue:2 | analyse | The pupil distinguishes a compulsory item from an optional item and checks both clauses against the sign; every option uses grammatical obligation expressions. |
| y6h-rescue:3 | evaluate | The pupil identifies the need, weighs distance against availability and rejects the tempting nearer but closed option; each option uses the same correct should structure. |
| y6h-rescue:4 | evaluate | The pupil evaluates two proposed actions against both an external rule and behavioural evidence, choosing a recommendation with a consistent reason. |
| y6h-castle:3 | evaluate | The pupil eliminates an insufficient option, compares the remaining sufficient options and chooses the smallest feasible one; identifying the biggest or smallest alone fails. |
| y6h-castle:4 | analyse | The pupil combines three comparative relationships, rules out different distractors for different reasons and finds the one object satisfying the complete set of constraints. |
